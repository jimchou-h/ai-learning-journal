## 3. Vue Best Practices 对齐检查（Vue 项目）

- [ ] 统一使用 Composition API + `<script setup lang="ts">`（如无项目级例外）
- [ ] 路由页面保持“组合/编排层”定位，复杂 UI 与逻辑已拆分到子组件或 composable
- [ ] 状态最小化：源状态放 `ref/reactive`，派生状态优先 `computed`
- [ ] 数据流清晰：props down / events up，双向绑定仅用于真实 `v-model` 契约
- [ ] 模板保持声明式：复杂分支和格式化逻辑已上移到 `computed`/方法
- [ ] 可复用副作用逻辑已抽到 `useXxx`，且 composable 不直接耦合页面通知（message/modal）
- [ ] 类型约束到位：减少 `any`，关键状态与业务值使用类型/枚举表达
- [ ] 本次改造有对应回归验证（关键路径 + 边界场景）
